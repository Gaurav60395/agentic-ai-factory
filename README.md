# AI-Based Jira Bug Intelligence Agent

An experimental **AI-driven Jira bug tracking agent** that analyzes defect information and automatically generates **smoke test cases** to support QA and automation workflows.

The project explores **agentic AI patterns** for defect reasoning, tool integration, and test case generation using Python.
